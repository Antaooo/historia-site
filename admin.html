HISTORIA Back-office

Connexion

Le site est publié depuis GitHub : le back-office enregistre tes modifications directement dans le dépôt, avec ton jeton d'accès GitHub. Le jeton reste dans ton navigateur et ne sert qu'à parler à GitHub.

Comment créer le jeton ?
  1. Sur GitHub : ta photo › Settings › Developer settings › Personal access tokens › Fine-grained tokens › Generate new token.
  2. Repository access : « Only select repositories », puis choisis historia-site.
  3. Permissions › Repository permissions › Contents : « Read and write ». Rien d'autre.
  4. Choisis une date d'expiration, génère le jeton, copie-le ici. Ne le partage avec personne.
